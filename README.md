Overview
========

This is the programming training for FRC Team 2637 The Phantom Catz. Please feel
free to use this for your own, private, purposes, as long as you attribute it to
us.

Compiling Files
---------------

You can read these files on GitHub, but you may want to read these in some other
format. A Makefile is provided to compile these files into HTML. To do so, you
should download [Pandoc](https://pandoc.org). You can then run `make` for the
individual topics or compile all of them at once.
